Open homes: twelve decisions

Agents and agencies can't enter open-home times today, so buyers never see any and Inspection AI has nothing to plan from. This adds the missing entry screen and import column. The buyer-side screens already exist, apart from the fixes in the box below.

Two buyer-side faults this build must also fix

Wrong time on the public page. The listing card formats times in the server's clock. On Vercel that is UTC, so Saturday 10:00 am in Melbourne would show as 11:00 pm on Friday. Nobody has seen it, because there have never been any times.

Times on sold homes. The listing card doesn't check the listing's status, so a home that sold on Thursday could still show Saturday's open home.

  1. A new "Open homes" tab on the listing

    It sits between Photos and Documents, on the agency and agent consoles, with one shared component. The count of upcoming times shows on the tab.

    RecommendedAlternative: a section inside Details. Rejected because Details saves the whole ad as one form, and times change far more often than the ad.
  2. Anyone who may edit the listing may set its times, with no owner approval

    This uses the existing listing:edit permission. An agent still needs an owner to publish an ad, but a time on a home that is already public is a fact the agent knows best, and open homes often change at short notice.

    RecommendedAlternative: every time goes through the owner's approval. Safer, but a Friday change could miss Saturday.
  3. Enter a day, a start time and a length

    The day defaults to the coming Saturday, or the Saturday after if that is within a day. The length chips are 15, 30, 45 and 60 minutes, or a chosen end time, and 30 is preselected.

    Recommended
  4. Times are always in the property's own time zone

    A Sydney agent listing a Perth home types Perth time, and the screen says "Perth time". The public page, the planner and the calendar file all use the same zone, whoever is looking.

    RecommendedAlternative: the agent's browser zone, as appointments use. Rejected because an open home happens at the property.
  5. Repeat weekly, up to 6 weeks, as separate times

    A tick and a number create one ordinary row per week, and the form previews them before saving. Each can then be changed alone. A row also has "Next week", which copies it 7 days on.

    RecommendedAlternative: a true repeating rule. More to build, and awkward when one week differs.
  6. Three kinds: Open home, By appointment and Auction

    The public card already has a label for each. Only Open home goes into the buyer's planner. An auction date is stored today, by import and the assistant, but no public page shows it and the Details form has no field for it. Adding an auction here also updates that stored date, in one transaction, and importing an auction date creates the row.

    RecommendedAlternative: Open home and By appointment only, leaving auctions for later. Buyers would still not see auction dates.
  7. Changes show on the public page straight away, and no buyer is messaged

    Saving clears the listing's public cache. A plan link already handles a removed time: the home moves to "Not this day" with its next time. A calendar file the buyer already downloaded can't be updated, and the Remove step says so.

    RecommendedAlternative: email buyers who chose that time. We don't record who chose it, because plans live only in the link, so this would need a new tracking feature.
  8. Times disappear from public view when the home leaves the market

    When a listing is sold, leased or withdrawn, its upcoming times stop showing at once, and they return if it goes live again. The rows stay, so nothing needs re-entering.

    Recommended
  9. Limits that stop mistakes

    A time must be in the future and within 6 months, and last between 10 minutes and 4 hours. It can't overlap another time on the same listing. A listing can hold 20 upcoming times and one upcoming auction. Outside 7 am to 8 pm, the form asks "Is this right?" but allows it.

    Recommended
  10. An open_homes column in CSV, Excel and Google Sheets import

    Format: 2026-11-14 10:00-10:30; 2026-11-21 10:00-10:30. It takes the property's time zone. A bad value warns on that row and still imports the listing. Importing adds new times and never deletes existing ones.

    RecommendedREAXML is a separate decision, because no REAXML importer exists yet.
  11. Left out of this build

    The console assistant adding times, showing open homes on the agent's calendar or Google and Outlook, an agency-wide "this weekend" page, alerts to buyers about new times, and attendance sign-in. Each can follow without changing this work.

    Recommended, so this launch blocker clears quicklyTell me if any of these must be in the first version. The agent's calendar is the one I'd add first.
  12. One small database change, migration 0091, with your go

    The table holds only the time and kind today, with no index beyond its primary key. This adds an index for reading a listing's times, a unique rule so the same time can't be saved twice, and who created each time. Nothing is removed and the table is empty, so the risk is low. Dev and production share this database, so it applies to the live site.

    Recommended
